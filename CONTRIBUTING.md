# Сдача домашних работ

Каждая работа выполняется в отдельной ветке `hw_n` и сдаётся PR в `main`.
Для HW1 локальная ветка `hw_1` уже подготовлена; `main` содержит начальный коммит.

## Первая публикация

1. Создайте в своём GitHub **публичный** репозиторий `beauty-assistant-mlsd`.
   Не добавляйте README, лицензию и `.gitignore` при создании: локальная история уже есть.
1. Выполните из папки проекта, заменив `YOUR_LOGIN` своим логином:

```bash
git remote add origin https://github.com/YOUR_LOGIN/beauty-assistant-mlsd.git
git push -u origin main
git push -u origin hw_1
```

3. Откройте PR: base `main`, compare `hw_1`, заголовок `HW1: дизайн ML-системы`.
   В описании укажите документ и результаты `uv run pre-commit run --all-files`.
1. Выдайте ментору доступ через **Settings → Collaborators** и добавьте ментора
   и назначенных кросс-ревьюверов в **Reviewers** PR.
   Для запроса ревью у внешнего участника может потребоваться доступ к репозиторию.
1. Дождитесь проверок и ревью; исправления отправляйте в ту же ветку.
   После одобрения слейте PR в `main`.

## Следующие работы

```bash
git switch main
git pull --ff-only
git switch -c hw_2
```

Перед коммитом запустите `uv run pre-commit run --all-files`.
Не включайте в публичную историю внутренние выгрузки, рабочие диалоги и секреты.
